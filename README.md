#  Expense Tracker

A simple Expense Tracker web application built using PHP and MongoDB.

This project is created as a college sub-assignment to demonstrate basic web development, CRUD operations, and MongoDB database queries.

##  Features

- Add a new expense
- View all expenses
- Edit an expense
- Delete an expense
- Search/filter expenses by category
- Display total expenses
- Store expense data in MongoDB

##  Technologies Used

- HTML
- CSS
- PHP
- MongoDB
- MongoDB Compass
- XAMPP
- Composer
- Git & GitHub
- Visual Studio Code
